About LifeOS

LifeOS is a cloud-hosted personal productivity software application operated by Luke Sheaffer, a sole proprietor based in the United States. The application connects to a user's task list and calendar and automatically generates task reminders, schedule alerts, and priority notifications. These notifications are delivered by SMS text message, through the Twilio messaging platform, to users who have explicitly enrolled. LifeOS sends only account-related notifications: it does not send marketing or promotional messages, and it never messages anyone who has not opted in.

This is a sole-proprietor program. The operator, Luke Sheaffer, is presently the only enrolled subscriber, opted in through the flow described below on his own verified mobile number.

How to opt in

Enrollment in LifeOS SMS notifications begins by text message. The opt-in call to action is:

From your own mobile phone, send the keyword START to +1 (201) 762-0827, the LifeOS notification number. By texting START to this number you agree to receive recurring automated task and schedule notification text messages from LifeOS (Luke Sheaffer). Message frequency varies; typically a few messages per day. Message and data rates may apply. Consent is not a condition of any purchase.

After you text START, you will receive a single enrollment confirmation message naming the brand, the message frequency, the "message and data rates may apply" disclosure, and HELP and STOP instructions.

Task and schedule notifications begin only after your LifeOS account is linked to that verified number. In the LifeOS application you tick a consent checkbox that is unchecked by default and carries the same disclosure text, then complete a one-time 6-digit confirmation code texted to your number. Consent is therefore captured and confirmed before any notification is sent.

This is the only opt-in path. Numbers are never purchased, rented, imported, or added by any third party.

What messages you will receive

Enrolled subscribers receive account notifications only:

  • Daily prioritized task lists
  • Task and schedule reminders
  • Daily score and progress updates

No marketing or promotional messages are sent.

Reply STOP to any LifeOS message at any time to cancel; you will receive one final confirmation message and nothing further. Reply HELP for help, or email the contact below.
